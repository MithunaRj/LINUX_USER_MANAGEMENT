# Linux User Management Project

## Overview

This project is a Bash scripting-based Linux User Management system that automates common user administration tasks. It provides an interactive menu-driven interface for managing user accounts on Linux systems.

## Features

* Create new users
* Delete existing users
* Lock user accounts
* Unlock user accounts
* Check user details
* Verify user existence
* Generate user management logs
* Interactive menu-driven interface

## Technologies Used

* Bash Scripting
* Linux User Administration Commands
* Shell Utilities

## Project Structure

```
Linux_user_management/
├── scripts/
│   └── user_management.sh
├── reports/
│   └── user_management.log
├── README.md
└── .gitignore
```

## Prerequisites

* Linux Operating System
* Bash Shell
* Sudo Privileges

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd Linux_user_management
```

3. Give execute permission:

```bash
chmod +x scripts/user_management.sh
```

4. Run the script:

```bash
sudo ./scripts/user_management.sh
```
